# SnapRAG ⚡
Zero-Trust On-Device Document Intelligence for Snapdragon-powered HP PCs.

## Concept
SnapRAG is a local RAG (Retrieval-Augmented Generation) system. It allows enterprise users to chat with confidential PDFs entirely offline, leveraging the Snapdragon NPU via models from the **Qualcomm AI Hub**.

## Qualcomm AI Hub Integration
This project is designed to utilize the **Llama 3** (for generation) and **MiniLM** (for embeddings) models from the Qualcomm AI Hub, ensuring fast, offline, and private inference directly on the Snapdragon NPU.
